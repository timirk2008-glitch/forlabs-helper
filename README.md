# Forlabs Helper (Chrome Extension) — v1.2

Браузерное расширение для портала электронного образования [bki.forlabs.ru](https://bki.forlabs.ru) (БКИ ИГУ).

## ✨ Возможности версии 1.2

- 🎨 **Движок цветовых тем (Color Themes Engine)**
  - Выпадающий список выбора оформления прямо в меню расширения.
  - Глубокая замена акцентных цветов по всему сайту: боковое меню, кнопки, активные вкладки, ссылки, бейджи, чекбоксы, сетка расписания, тестирование и диалоги.
  - Темы в комплекте:
    - **«Стандартная (Бирюзовая)»**: классическая фирменная палитра `#0c7087` / `#035063`.
    - **«Аметист (Фиолетовая)»**: глубокий королевский пурпур `#2e1065` и фиолетовые акценты `#7c3aed`.
    - **«Я хочу Вкусно и точка»**: аутентичная палитра бренда (тёмно-зелёный `#193f2d`, фирменный оранжевый `#ee7203`, акцентный бургер-красный `#e8410f`), замена логотипа в свернутом и развернутом виде, оригинальные шрифты с сайта, адаптированные фоны под тёмную (тёплый графит) и светлую тему (крафтовый кремовый), а также замена фонового изображения главной страницы на легендарный мем *«Я хочу Вкусно и точка. Понимаете?»*.
  - Идеальная стыковка со всеми остальными функциями: тёмной/светлой темой, стилями меню, кастомным скроллбаром (бегунок автоматически окрашивается в акцентные цвета темы, например, в цвет бургер-точки `#e8410f` для «Вкусно и точка»), индикатором активной вкладки при скругленном интерфейсе, глассморфизмом (с отдельными полупрозрачными стеклянными оттенками) и адаптивным контрастом текста.

- 🌙 **Тёмная тема (Dark Theme)**
  - Чистое перекрашивание (Pure Color Replacement) без добавления лишних рамок и с сохранением оригинальных акцентов.
  - Поддержка всех разделов: ЛК, Расписание, Вебинары, Программа курса, Отклик на задание, Тестирование, Кабинет администратора.
  - Кнопка быстрого переключения прямо в шапке сайта (рядом с профилем).

- 🧭 **Стили бокового меню (Navigation Styles)**
  - **Оригинальное**: классическая боковая панель портала.
  - **Компактное (Hover)**: аккуратная колонка иконок шириной 50px, плавно раскрывающаяся поверх контента при наведении.
  - **В шапке сайта**: пункты меню перемещаются в верхнюю панель управления, освобождая всю ширину страницы.

- 🛠️ **Фиксы интерфейса (UI Fixes)**
  - Исправление глитчей выпадающих списков `ui-select` и выравнивание высоты строк.
  - Удаление паразитных белых прямоугольных обводок фокуса при клике по кнопкам.
  - Строгие прямые углы и гармоничные тени возвышения шапки и меню.

- 📜 **Кастомный скроллбар (Custom Scrollbar)**
  - Минималистичный полупрозрачный ползунок с прозрачным треком, динамически адаптирующийся под активную цветовую тему.

- 🫧 **Скругленный интерфейс (Rounded Interface)**
  - Суперскругленные плашки, карточки, поля ввода и кнопки.
  - Строгое соблюдение математического правила внутреннего и внешнего скругления ($R_{ext} = R_{int} + p$).
  - Динамическое объединение смежных сообщений одного пользователя в диалогах (скругление внешних углов группы).

- 🪟 **Глассморфизм (Glassmorphism)**
  - Эффект матового стекла (`backdrop-filter: blur(20px)`) для шапки сайта с плавным прокручиванием контента под ней.
  - Эффект матового стекла для бокового меню с сохранением оттенка выбранной темы.
  - Стеклянная строка поиска со световыми рефлексами и стеклянными рамками.

- ⚙️ **Всплывающее меню (Popup)**
  - Независимое включение и выключение каждой функции.
  - Мгновенная синхронизация между открытыми вкладками без перезагрузки страниц.
  - Моментальное применение без мерцания белого экрана (Anti-FOUC).

## 🚀 Установка в Google Chrome

1. Откройте страницу управления расширениями:
   - В Google Chrome перейдите по адресу: `chrome://extensions/`
2. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку проекта (`forlabs go`).
5. Откройте или обновите сайт [https://bki.forlabs.ru/app](https://bki.forlabs.ru/app).
