# Forlabs Helper (Chrome Extension)

Браузерное расширение для портала образования [bki.forlabs.ru](https://bki.forlabs.ru) (БКИ ИГУ).

## ✨ Возможности
- 🌙 **Тёмная тема**
- 🔘 **Кнопка переключения в шапке**
- ⚙️ **Всплывающее окно (Popup)**:
  - Удобный тумблер включения/выключения темы.
  - Модульная архитектура с заделом под новые функции (Кастомизируемое расписание, Уведомления о ДД и др.).

## 🚀 Установка в Google Chrome
1. Откройте в браузере страницу управления расширениями:
   - В Google Chrome: `chrome://extensions/`
2. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите эту папку (`forlabs go`).
5. Откройте или обновите сайт [https://bki.forlabs.ru/app](https://bki.forlabs.ru/app).

